# Worldgen Router

Worldgen is a local-first runtime for building and maintaining a portable World Package from source material while preserving provenance and uncertainty boundaries.

## Start here

1. `AGENTS.md`
2. `.mex/continuity/CURRENT.md`
3. Relevant context files in `.mex/context/`
4. Relevant implementation and tests in `src/worldgen/` and `tests/`

## Where things live

- **Accepted architecture and implementation context:** `.mex/context/architecture.md`, `.mex/context/implementation.md`
- **Conventions:** `.mex/context/conventions.md`
- **Decisions and ADR index:** `.mex/context/decisions.md`, `docs/development/`
- **Evidence-backed development patterns:** `.mex/patterns/INDEX.md`
- **Current state and historical continuity:** `.mex/continuity/CURRENT.md`, `.mex/continuity/DEVELOPMENT.md`

## End-of-session maintenance

After substantial work:
- Update `.mex/continuity/CURRENT.md` with current milestone state, open questions, and next steps.
- Append a concise entry to `.mex/continuity/DEVELOPMENT.md` for durable milestones/decisions.
- Update affected context/pattern files only when repository evidence changed.
